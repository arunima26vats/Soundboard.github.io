# Soundboard.github.io
🎧 Soundboard Visualizer

A minimal, interactive web-based soundboard with a real-time audio visualizer, dynamic UI reactions, and a vinyl-themed loading page. Built entirely with HTML, CSS, and JavaScript using the Web Audio API — no external libraries.

✨ Features

🎵 Soundboard buttons
Play multiple sound effects (Kick, Clap, Pop, Synth, Dog, Cat).

📈 Real-time audio visualizer
Thin waveform synced to sound using the Web Audio API.

🟧 Animated UI reactions

Quote text reacts to bass

Divider pulses with sound

Buttons animate when clicked

🎚 Volume control

Slider to adjust volume

Text-only Mute / Unmute button (no hover circle)

💿 Vinyl loading page

Full-page loading screen

Spinning vinyl animation

“Click to Start” (unlocks audio context)

🌐 Custom favicon

Same vinyl image appears in browser tab

🚫 No external libraries

✅ Works fully offline with local sounds

🧱 Tech Stack

HTML5

CSS3

Vanilla JavaScript

Web Audio API

Canvas API
